% =========================================================
% 1. Objective
% =========================================================
\section{Objective}
To learn software package management in Linux using APT:
\begin{itemize}[noitemsep,topsep=1pt,leftmargin=1.2em]
  \item Refresh package lists (\cmd{sudo apt update}) and upgrade packages (\cmd{sudo apt upgrade}).
  \item Install software packages (\cmd{sudo apt install}).
  \item Compare removing software (\cmd{remove}) vs completely deleting settings (\cmd{purge}).
  \item Remove unused dependencies (\cmd{sudo apt autoremove}).
\end{itemize}

% =========================================================
% 2. Theoretical Background
% =========================================================
\section{Theoretical Background}
Linux uses package managers like \cmd{apt} to fetch, install, update, and remove software packages from official repositories.

\subsection{Commands Practiced in This Lab}
\vspace{-2pt}
\begin{table}[h!]
\centering\footnotesize
\renewcommand{\arraystretch}{1.06}
\begin{tabularx}{\linewidth}{llp{5.4cm}X}

\midrule
\cmd{update} & \texttt{sudo apt update} & Refresh package list from repositories. & \texttt{sudo apt update} \\
\cmd{upgrade} & \texttt{sudo apt upgrade} & Upgrade installed packages to newest versions. & \texttt{sudo apt upgrade} \\

\cmd{autoremove} & \texttt{sudo apt autoremove} & Remove unused leftover dependencies. & \texttt{sudo apt autoremove} \\
\cmd{purge} & \texttt{sudo apt purge <pkg>} & Completely delete package and configuration files. & \texttt{sudo apt purge htop} \\
\bottomrule
\end{tabularx}

% =========================================================
% 4. Procedure / Steps
% =========================================================
\section{Procedure / Steps}
\begin{enumerate}[noitemsep,topsep=1pt,leftmargin=1.4em]
  \item Update package repository lists using \cmd{sudo apt update}.
  \item Simulate system package upgrade using \cmd{sudo apt upgrade}.
  \item Install utilities \cmd{htop} and \cmd{tree} using \cmd{sudo apt install -y htop tree}.
  \item Verify installed paths using \cmd{which htop tree}.
  \item Remove \cmd{tree} package using \cmd{sudo apt remove -y tree}.
  \item Remove unused dependencies using \cmd{sudo apt autoremove -y}.
  \item Purge \cmd{htop} and all config files using \cmd{sudo apt purge -y htop}.
  \item Verify removal using \cmd{which htop}.
\end{enumerate}

% =========================================================
% 6. Conclusion
% =========================================================
\section{Conclusion}
Key takeaways:
\begin{enumerate}[noitemsep,topsep=1pt,leftmargin=1.4em]
  \item \cmd{apt update} refreshes repository lists, while \cmd{apt upgrade} updates installed software.
  \item \cmd{apt install} downloads and installs programs with required dependencies.
  \item \cmd{apt remove} removes binaries, while \cmd{apt purge} wipes configuration files as well.
  \item \cmd{apt autoremove} cleans orphaned dependencies to free disk space.
\end{enumerate}
