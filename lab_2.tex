% =========================================================
% 1. Objective
% =========================================================
\section{Objective}
To practice basic Linux navigation and file listing commands:
\begin{itemize}[noitemsep,topsep=1pt,leftmargin=1.2em]
  \item Check current user (\cmd{whoami}) and location (\cmd{pwd}).
  \item Move between directories (\cmd{cd}, \cmd{cd \textasciitilde}).
  \item List files, hidden files, and details (\cmd{ls}, \cmd{-l}, \cmd{-a}, \cmd{-lh}, \cmd{-la}).
\end{itemize}

% =========================================================
% 2. Theoretical Background
% =========================================================
\section{Theoretical Background}
Linux uses a single directory tree starting at root (\cmd{/}). Users start in home (\cmd{\textasciitilde}). Commands navigate and inspect files.

\subsection{Commands Practiced in This Lab}
\vspace{-2pt}
\begin{table}[h!]
\centering\footnotesize
\renewcommand{\arraystretch}{1.06}
\begin{tabularx}{\linewidth}{llp{5.4cm}X}
\toprule
\textbf{Command} & \textbf{Syntax} & \textbf{Simple Meaning / Purpose} & \textbf{Example} \\
\midrule
\cmd{whoami} & \texttt{whoami} & Print current username. & \texttt{whoami} \\
\cmd{pwd} & \texttt{pwd} & Print current directory path. & \texttt{pwd} \\
\cmd{cd} & \texttt{cd [dir]} & Move to directory. & \texttt{cd lab\_demo} \\
\cmd{cd \textasciitilde} & \texttt{cd \textasciitilde} & Go to home directory. & \texttt{cd \textasciitilde} \\
\cmd{ls} & \texttt{ls} & List visible files and folders. & \texttt{ls} \\
\cmd{ls -l} & \texttt{ls -l} & Long listing with file details. & \texttt{ls -l} \\
\cmd{ls -a} & \texttt{ls -a} & List all files, including hidden (\texttt{.} prefix). & \texttt{ls -a} \\
\cmd{ls -lh} & \texttt{ls -lh} & Show human-readable sizes (K, M, G). & \texttt{ls -lh} \\
\cmd{ls -la} & \texttt{ls -la} & Show all files with full details. & \texttt{ls -la} \\
\bottomrule
\end{tabularx}
\end{table}
\vspace{-6pt}

\subsection{Understanding File Details (\texttt{ls -l})}
Running \cmd{ls -l} shows six key fields for each file:
\vspace{-2pt}
\begin{table}[h!]
\centering\footnotesize
\renewcommand{\arraystretch}{1.06}
\begin{tabularx}{\linewidth}{p{3.2cm}X}
\toprule
\textbf{Field} & \textbf{Simple Explanation} \\
\midrule
\textbf{1. File Type \& Permissions} & Type (\texttt{-} file, \texttt{d} folder) and access rights (\texttt{rwx}) for owner, group, others. \\
\textbf{2. Links} & Number of hard links. \\
\textbf{3. Owner \& Group} & User and group that own the file. \\
\textbf{4. File Size} & Size in bytes (or KB/MB with \cmd{-h}). \\
\textbf{5. Date \& Time} & Last modification timestamp. \\
\textbf{6. File Name} & Name of file or folder. \\
\bottomrule
\end{tabularx}
\end{table}
\vspace{-6pt}

% =========================================================
% 4. Procedure / Steps
% =========================================================
\section{Procedure / Steps}
Steps followed in this experiment:
\begin{enumerate}[noitemsep,topsep=1pt,leftmargin=1.4em]
  \item Check current user (\cmd{whoami}) and directory path (\cmd{pwd}).
  \item List home directory contents (\cmd{ls}).
  \item Move into demo folder (\cmd{cd lab\_demo}) and verify with \cmd{pwd}.
  \item List normal files (\cmd{ls}) and hidden files (\cmd{ls -a}).
  \item Inspect file details in bytes (\cmd{ls -l}) and readable units (\cmd{ls -lh}).
  \item List all files with full attributes (\cmd{ls -la}).
  \item Return to home directory (\cmd{cd \textasciitilde}).
\end{enumerate}
