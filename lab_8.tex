\section{Problem}
In operating systems, process scheduling decides the order of process execution on the CPU. The objective of this lab is to implement the \textbf{First Come, First Served (FCFS)} CPU scheduling algorithm in C++.

The program must:
\begin{itemize}[noitemsep,topsep=1pt,leftmargin=1.2em]
  \item Take the number of processes ($n$), arrival time ($AT$), and execution/burst time ($BT$) for each process.
  \item Validate input data (positive count, non-negative arrival time, and positive execution time).
  \item Schedule processes strictly in order of their arrival time using stable sorting.
  \item Compute Start Time ($ST$), Completion Time ($CT$), Turnaround Time ($TAT$), and Waiting Time ($WT$).
  \item Calculate and display Average Waiting Time and Average Turnaround Time.
  \item Display the execution schedule table and text-based Gantt chart timeline.
\end{itemize}

\section{Theoretical Solution}
First Come, First Served (FCFS) is the simplest non-preemptive CPU scheduling algorithm. The process that arrives first in the ready queue is allocated the CPU first.

\subsection{Key Principles}
\begin{itemize}[noitemsep,topsep=1pt,leftmargin=1.2em]
  \item \textbf{FIFO Queue Discipline:} Processes are serviced strictly in arrival sequence.
  \item \textbf{Non-Preemptive Execution:} Once a process gets the CPU, it runs to completion without interruption.
  \item \textbf{Tie-Breaking:} When arrival times match, input order is maintained via stable sorting.
  \item \textbf{CPU Idle Handling:} If the CPU finishes before the next process arrives, current time jumps forward: $ST_i = \max(currentTime, AT_i)$.
\end{itemize}

\subsection{Formulas}
For each process $i$, scheduling metrics are computed as follows:
\begin{itemize}[noitemsep,topsep=1pt,leftmargin=1.2em]
  \item \textbf{Start Time ($ST$):} $ST_i = \max(currentTime, AT_i)$
  \item \textbf{Completion Time ($CT$):} $CT_i = ST_i + BT_i$
  \item \textbf{Turnaround Time ($TAT$):} $TAT_i = CT_i - AT_i$
  \item \textbf{Waiting Time ($WT$):} $WT_i = ST_i - AT_i = TAT_i - BT_i$
  \item \textbf{Average Turnaround Time ($Avg\_TAT$):} $\frac{1}{n} \sum_{i=1}^{n} TAT_i$
  \item \textbf{Average Waiting Time ($Avg\_WT$):} $\frac{1}{n} \sum_{i=1}^{n} WT_i$
\end{itemize}

\subsection{Algorithmic Approach}
\begin{enumerate}[noitemsep,topsep=1pt,leftmargin=1.4em]
  \item Read process count $n$ and validate that $n > 0$.
  \item Read arrival ($AT$) and execution ($BT$) times; validate $AT \ge 0$ and $BT > 0$.
  \item Sort processes in ascending order of arrival time using \cmd{std::stable\_sort}.
  \item For each process $i$: update $currentTime = \max(currentTime, AT_i)$, set $start = currentTime$, compute $waiting = start - AT_i$, advance $currentTime = currentTime + BT_i$, and record $completion = currentTime$ and $turnaround = completion - AT_i$.
  \item Sort back by process ID, print results table, display averages, and output Gantt chart.
\end{enumerate}

\section{Source Code}
The complete C++ implementation of the First Come, First Served CPU scheduling algorithm is given below:

\begin{lstlisting}
#include <bits/stdc++.h>
using namespace std;

struct Process {
    int id;
    int arrival;
    int execution;
    int start;
    int completion;
    int turnaround;
    int waiting;
};

int main() {
    int n;

    cout << "Enter the number of processes: ";
    cin >> n;

    if (cin.fail() || n <= 0) {
        cout << "Invalid number of processes!\n";
        return 1;
    }

    vector<Process> processes(n);

    // Input process details
    for (int i = 0; i < n; i++) {
        processes[i].id = i + 1;

        cout << "Enter arrival and execution time for process "
             << processes[i].id << ": ";

        cin >> processes[i].arrival >> processes[i].execution;

        if (cin.fail() ||
            processes[i].arrival < 0 ||
            processes[i].execution <= 0) {
            cout << "Invalid input! Arrival time must be "
                 << "non-negative and execution time must "
                 << "be positive.\n";
            return 1;
        }
    }

    // Sort by arrival time; preserve input order for ties
    stable_sort(processes.begin(), processes.end(),
        [](const Process& a, const Process& b) {
            return a.arrival < b.arrival;
        });

    int currentTime = 0;
    double totalWaiting = 0;
    double totalTurnaround = 0;

    // Calculate scheduling times
    for (Process& p : processes) {
        // Handle CPU idle time
        currentTime = max(currentTime, p.arrival);

        p.start = currentTime;
        p.waiting = p.start - p.arrival;

        currentTime += p.execution;

        p.completion = currentTime;
        p.turnaround = p.completion - p.arrival;

        totalWaiting += p.waiting;
        totalTurnaround += p.turnaround;
    }

    // Display results in original process order
    sort(processes.begin(), processes.end(),
        [](const Process& a, const Process& b) {
            return a.id < b.id;
        });

    cout << "\nProcess\tArrival\tExecution\tStart\tCompletion"
         << "\tTurnaround\tWaiting\n";

    for (const Process& p : processes) {
        cout << "P" << p.id << "\t"
             << p.arrival << "\t"
             << p.execution << "\t\t"
             << p.start << "\t"
             << p.completion << "\t"
             << p.turnaround << "\t\t"
             << p.waiting << '\n';
    }

    // Display average times
    cout << fixed << setprecision(2);

    cout << "\nAverage Waiting Time: "
         << totalWaiting / n << '\n';

    cout << "Average Turnaround Time: "
         << totalTurnaround / n << '\n';

    // Display Gantt chart in FCFS execution order
    stable_sort(processes.begin(), processes.end(),
        [](const Process& a, const Process& b) {
            return a.arrival < b.arrival;
        });

    cout << "\nGantt Chart:\n";

    for (const Process& p : processes) {
        if (p.start > 0 && p.start > p.arrival) {
            // The CPU may have been idle before this process.
            // Idle intervals are displayed below using timestamps.
        }

        cout << "| ";
        if (p.start > 0) {
            cout << "P" << p.id << " ";
        } else {
            cout << "P" << p.id << " ";
        }
    }
    cout << "|\n";

    // Print process start and completion timestamps
    if (!processes.empty()) {
        cout << processes[0].start;

        for (const Process& p : processes) {
            cout << "\t" << p.completion;
        }

        cout << '\n';
    }

    return 0;
}
\end{lstlisting}
